Project Objective

To create a repeatable application deployment workflow by connecting source code with AWS deployment services.


The project demonstrates how application changes can move through the configured pipeline and reach an Elastic Beanstalk environment.

Implementation Checklist

  • Application source code
  • Elastic Beanstalk environment
  • CodePipeline configuration
  • Deployment validation
